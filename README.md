# Информатор

Автоинформатор для телефона: объявления остановок старыми голосами. Это переписанный «Информатор» для RP в Метрострое (ista011, 2015; alTerr, 2018), сделанный как PWA для Android.

- Пакеты старого Информатора (`.zip` с `.cfg` внутри) импортируются как есть.
- Линии: справочники остановок со звуками названий, фразами и шаблонами объявлений.
- Маршрут — это кольцо остановок по линии. Отметки «конечная» делят его на направления, а остановки «туда» и «обратно» могут отличаться.
- Пропуск остановок («без остановки») и начальное объявление электрички со списком пропускаемых.
- Регулярные объявления, например «в парк» или «держитесь за поручни». Их можно включать прямо на ходу.
- Служебные сообщения: кнопками в пульте или с привязкой «после объявления» с паузой.
- Нарезка длинной записи на объявления по паузам.
- Управление с экрана блокировки и кнопками гарнитуры.

Все звуки хранятся только на устройстве, в IndexedDB. В репозитории их нет.

Установка: открыть страницу GitHub Pages в Chrome → меню → «Установить приложение».
